# Посмотри в окно

Проектная работа Яндекс Практикума: вёрстка интерфейса приложения для просмотра видео из окон разных городов.

## Технологии

- HTML, CSS (Flexbox)
- Кастомные чекбоксы и состояния элементов (:hover, :active, :focus-visible)
- Обрезка текста (text-overflow, line-clamp)

Ссылка на репозиторий: https://github.com/Pluggiyaki/posmotri-v-okno-ad
